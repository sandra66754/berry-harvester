\# Berry Harvester



\## Описание

Программа для нахождения максимального сбора черники за один подход.



\## Как запустить

python berry\_compressor.py



\## Формат ввода

\- Первая строка: число N (3 ≤ N ≤ 1000)

\- Вторая строка: N целых чисел (1 ≤ ai ≤ 1000)



\## Формат вывода

\- Одно число — максимальная сумма ягод



\## Пример

Вход:

4

1 2 3 4



Выход:

9



\## Запуск тестов

python -m unittest test\_berry.py
